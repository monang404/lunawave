Kamu eksekutor kode untuk project LunaWave (repo ini). Sebelum melakukan apapun:

1. Baca AI_CONTEXT.md di root repo — ini aturan wajib (file restricted,
   batasan teknis, alur kerja "sebelum/setelah selesai").
2. Baca scratch/patches/IMPLEMENTATION_PLAN.md — ini rencana kerja yang
   sudah difilter dari 13 dokumen bug report, sudah dibagi 12 batch per
   file, duplikat sudah dihapus, keputusan untuk bug yang solusinya
   bentrok sudah diambil. JANGAN re-analisa dari nol, ikuti urutan batch
   di dokumen itu apa adanya.
3. Tiap batch merujuk ke bagian spesifik di file
   scratch/patches/PATCH_*.md (kolom "Ambil diff dari"). Buka HANYA
   bagian yang dirujuk untuk diambil diff-nya — jangan baca seluruh file
   sumber kalau tidak perlu, hemat context.
4. Kerjakan satu batch sekali jalan: edit file → jalankan
   `python -m pytest tests/ -x -q` → kalau pass, append satu entri baru
   ke docs/PATCHLOG.md (format ID PATCH-YYYY-MM-DD-NNN, lanjutkan dari
   latest_patch_id di frontmatter-nya) → baru lanjut ke batch berikutnya.
5. Kalau snippet "Cari:" di dokumen sumber tidak persis cocok dengan isi
   file saat ini (kode sudah berubah), STOP dan laporkan ke saya — jangan
   menebak/memaksakan patch.
6. server/handlers/websocket.py itu restricted file — izin sudah
   diberikan (tertulis di IMPLEMENTATION_PLAN.md Batch 9), tapi tetap
   kerjakan sebagai satu pass, jangan disentuh di batch lain.
7. Setelah SEMUA batch selesai: jalankan `python scripts/run_all.py`,
   laporkan hasilnya.

Mulai dari Batch 1. Setiap selesai satu batch, laporkan singkat (file
yang diubah + hasil test), lalu TUNGGU konfirmasi saya sebelum lanjut
batch berikutnya.
