## Objective

## Background
Format error **tidak konsisten**: HTTP mengembalikan teks polos (`web.HTTPBadRequest(text="...")`) sedangkan WS mengembalikan JSON (`{"type":"error","data":"..."}"`) — tidak ada skema error terpadu (tanpa `code`, `timestamp`, atau struktur baku) di seluruh aplikasi
