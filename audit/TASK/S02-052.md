# Task ID: S02-052

**Title:** CacheResolver._fetching tidak dilengkapi pengaman lock atomic asyncio
**Priority:** P1
**Sprint:** sprint-02-stability
**Status:** TODO

## Source Audit
[ARCH-A14]

## Root Cause
Dictionary _fetching rentan race condition dalam blok asyncio karena dua coroutine bisa melewati pengecekan variabel sebelum sempat mengunci, yang pada akhirnya malah menciptakan overhead query yt-dlp ganda untuk video yang sama.

## Location
`cache/resolver.py:42-47`

## Current Behavior
Rangkaian kamus pengait status `_fetching` dieksekusi secara asinkron (Coroutines) terbuka telanjang tanpa dilapisi benteng proteksi gembok pengunci utas `asyncio.Lock()`, menimbulkan bahaya balap kondisi lintasan (Race Condition) jika dua penjemput meminta stream URL yang sama serentak.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Gunakan mekanisme penguncian (contoh: asyncio.Lock) untuk mencegah race condition. Bungkus akses variabel mutasi dalam blok `async with lock:`.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
