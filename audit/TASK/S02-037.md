# Task ID: S02-037

**Title:** _pending Dict di MpvController Tidak Dibersihkan Saat Timeout
**Priority:** P1
**Sprint:** sprint-02-stability
**Status:** TODO

## Source Audit
[PERF-P15]

## Root Cause
Block future asinkron _pending berpotensi menggantung tak terhapus jika terinterupsi intervensi diluar jangkauan TimeOut (misal dari CancelledError yang membunuh proses secara mutlak), berujung memori membengkak.

## Location
`engine/mpv_controller.py:284-290`

## Current Behavior
Blok eksekusi `await asyncio.wait_for` hanya menangkap `OSError` dan `TimeoutError`. Jika task induk di-cancel (melempar `asyncio.CancelledError`), future di dalam dict `_pending` tidak akan pernah di-pop dan menggantung abadi di memori, berpotensi memory leak.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Gunakan mekanisme penguncian (contoh: asyncio.Lock) untuk mencegah race condition. Bungkus akses variabel mutasi dalam blok `async with lock:`.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
