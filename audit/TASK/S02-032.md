# Task ID: S02-032

**Title:** EventBus.subscribe() dengan tipe closure tidak terlindungi garbage collector
**Priority:** P1
**Sprint:** sprint-02-stability
**Status:** DONE

## Source Audit
[ARCH-A18]

## Root Cause
Lambda atau fungsi nested tak berstatus unbound method yang didaftarkan pada event_bus diikat secara statis (strong reference), tidak terserap oleh clean up weakref, sehingga menimbulkan akumulasi memory leak.

## Location
`core/event_bus.py:33-37`

## Current Behavior
Fungsi lambda atau handler nested dicatat menggunakan _strong reference_ alias disalin paksa ke array, yang akan mencegah garbage collector membersihkan variabel objek tersebut secara permanen sehingga rawan menjadi _memory leak_.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Implementasikan mekanisme garbage collection atau batas ukuran (max limit) serta timeout/pruning untuk mencegah kebocoran memori (memory leak).

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
