## Root Cause
Kekokohan infrastruktur jaringan real-time streaming tak dibackup oleh profil beban (benchmark perf) pengujian jumlah maksimal bandwidth / koneksi klien (load test) membahayakan kapabilitas server crash bila dihantam banyak user.

## Location
`(Global Test Suites)`

## Current Behavior
Absennya test profil beban atau stresstest (misal menggunakan tool locust atau wrk) meloloskan skenario kemungkinan bottleneck stream async I/O bila dihajar traffic listener.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Tulis unit test/integration test baru menggunakan mock yang mensimulasikan lingkungan sebenarnya (misalnya HTTP request asli) yang diverifikasi dengan assertion.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
