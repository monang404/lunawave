# Task ID: S03-012

**Title:** getHashtagColor() Warna Acak Tidak Konsisten Antar Session
**Priority:** P2
**Sprint:** sprint-03-performance
**Status:** DONE

## Source Audit
[PERF-P18, FE-021]

## Root Cause
Variabel hash-color di injeksi menggunakan fungsi Math.random bawaan yang bersifat temporal dan menumpang memori lokal, akibatnya rentetan tag artis yang sama akan meleset gradasinya secara random setiap kali web client refresh halaman. Warna penanda chip genre dirender dengan Math.random() in-memory alih-alih di-hash statis dari title-nya, mengakibatkan pergeseran tone warna kapan pun DOM berubah atau browser me-load halaman.

## Location
`web/static/js/render/discover.js:1-9`

## Current Behavior
Pewarnaan elemen UI hash tag/genre sepenuhnya diundi dengan algoritma `Math.random()`. Walaupun menggunakan dictionary memory sementara, warna akan hilang/berubah drastis ketika page _refresh_.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Implementasikan mekanisme garbage collection atau batas ukuran (max limit) serta timeout/pruning untuk mencegah kebocoran memori (memory leak).

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
