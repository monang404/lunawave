**Title:** JSON.stringify(track) di Setiap Render Item (Expensive per Frame)
**Priority:** P2
**Sprint:** sprint-03-performance
**Status:** DONE

## Source Audit
[PERF-P06]

## Root Cause
Saat membangun antrean layout lagu (discover/recent), metadata direkam ke attribut JSON-text via stringify per baris objek secara simultan. Sangat mendegradasi resource memory-thread browser pada iterasi data berjumlah banyak.

## Location
`web/static/js/render/discover.js:126, 192, 412`

## Current Behavior
Operasi mahal serialisasi obyek metadata (`JSON.stringify`) diulang tanpa belas kasihan di dalam iterasi per-item list hasil *Discover* dan *Recent*, yang bisa berpotensi menghabiskan daya *scripting* Frame secara instan.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
