# Task ID: S01-001

**Title:** CORS wildcard pada endpoint audio
**Priority:** P1
**Sprint:** sprint-01-security
**Status:** DONE

## Source Audit
[EXEC-007]

## Root Cause
Konfigurasi CORS menggunakan wildcard (Access-Control-Allow-Origin: *) pada endpoint /api/stream/{id}, sehingga audio dapat di-embed oleh domain mana saja.

## Location
`server/handlers/http.py:157-164`

## Current Behavior
Endpoint stream `serve_stream` secara vulgar mengatur _hardcode_ `Access-Control-Allow-Origin` menjadi `*` (wildcard) yang memungkinkan sembarang asal domain membaca audio ini.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Konfigurasikan security headers HTTP dengan ketat. Hilangkan wildcard '*' dari konfigurasi CORS Allow-Origin dan batasi domain asal.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
