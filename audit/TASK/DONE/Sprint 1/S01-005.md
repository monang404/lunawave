# Task ID: S01-005

**Title:** WebSocket di-expose ke global scope window
**Priority:** P1
**Sprint:** sprint-01-security
**Status:** DONE

## Source Audit
[EXEC-043, ARCH-A12]

## Root Cause
Front end membuka kerentanan atau masalah privasi state dengan mengekspos WebSocket via window.ws = ws ke global scope. File javascript dimuat ke dalam global name space HTML satu demi satu (classic scripts). Semua objek (store, ws, localAudio) dilempar bertumpuk menaikkan peluang collision, tak punya encapsulation, dan tak bisa dilakukan unit test.

## Location
`web/static/js/ws.js:18`

## Current Behavior
Objek koneksi websocket mentah diekspos secara vulgar ke scope `window` global pada browser klien, memungkinkan campur tangan atau intrusi skrip luar (XSS).

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Tulis unit test/integration test baru menggunakan mock yang mensimulasikan lingkungan sebenarnya (misalnya HTTP request asli) yang diverifikasi dengan assertion.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
