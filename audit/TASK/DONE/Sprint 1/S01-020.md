**Title:** Volume Docker Hanya Mount /app/data, Cache dan Logs Hilang Saat Restart
**Priority:** P1
**Sprint:** sprint-01-security
**Status:** DONE

## Source Audit
[DEVOPS-004]

## Root Cause
Konfigurasi Compose me-mount 1 direktori belaka (/app/data), sementara tumpukan berharga cache download, catatan history log, serta pendaftaran pasword admin (/app/cache) akan tersapu rata dan musnah tak berbekas begitu container direstart.

## Location
`docker-compose.yml:10-11`

## Current Behavior
Direktori operasional persisten yang ditunjuk cuma tunggal `/app/data` (basis data SQlite), namun direktori utama `/app/cache` (menyimpan token admin di `admin_password.txt`, socket cache list) dilewatkan sirna jika container reboot.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
