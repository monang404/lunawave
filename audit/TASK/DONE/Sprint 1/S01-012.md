[API-02]

## Root Cause
Titik henti stream bersifat terbuka lebar ke publik. Semua yang memiliki kode identifikasi Youtube acak dapat memerintahkan server menarik data url di latar belakang, menguras sumber daya secara ilegal serta melanggar term of service YouTube tanpa jejak token.

## Location
`server/handlers/http.py:48-189`

## Current Behavior
Rute API `/api/stream/{video_id}` sama sekali tidak dibungkus pengecekan token header (Authentication API), tidak seperti WS yang memerlukan handshake login. Siapapun yang menebak urlnya bisa menyedot bandwidth hosting gratis (HTTP Stream Hijacking).

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Konfigurasikan security headers HTTP dengan ketat. Hilangkan wildcard '*' dari konfigurasi CORS Allow-Origin dan batasi domain asal.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
