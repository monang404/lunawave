# Task ID: S05-007

**Title:** Lyrics sync double requestAnimationFrame
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** DONE

## Source Audit
[EXEC-018]

## Root Cause
Pemanggilan fungsi lirik menjalankan requestAnimationFrame(() => syncLocalLyrics()) pada setiap tik progress, menghasilkan double RAF setiap detiknya.

## Location
`web/static/js/ws.js:149-151`

## Current Behavior
Kode memicu fungsi `requestAnimationFrame` di handler "progress" yang ditembak berulang-ulang saat koneksi WS aktif tiap detiknya untuk sinkronisasi lirik.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Terapkan debouncing dengan variabel `window._syncLyricsRaf` yang akan di-check sebelum memanggil `requestAnimationFrame` dan di-reset setelah callback dieksekusi untuk mencegah stack frame yang bertumpuk.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
