# Task ID: S05-075

**Title:** Structlog Tidak Menyertakan Correlation ID / Request ID
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** TODO

## Source Audit
[DEVOPS-026]

## Root Cause
Perekam barisan pesan log buta-buta membom penulisan pesan tanpa dibekali token id berantai (Req ID). Begitu server padat dipakai paralel, admin akan mual muntah mengurai membedakan baris log mana yang milik rute user 1 dibanding rute event user 2 (pencampuran baris pusing).

## Location
`core/log_config.py:458-464`

## Current Behavior
Penyusunan daftar _processor_ log Structlog buta tidak menginjeksikan modul perangkai jejak koneksi (`correlation ID` atau `request ID`), menyebabkan pencatatan rentetan _event_ pengguna di-konsol akan bercampur-aduk (_interleaved_) membingungkan jika diakses multi user.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
