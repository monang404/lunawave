# Task ID: S05-062

**Title:** DownloadManager._download_lock Memblokir Task Kedua Selamanya
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** TODO

## Source Audit
[CC-04]

## Root Cause
Lock antrean handler mendownload tak mengikat klausul tenggang wait_for() sama sekali. Kalau antrean task ke-1 memakan waktu super lama/nge-hang dari internet lemot, maka task pen-download file track kedua terparkir pasif mematung (starvation limit) tanpa konfirmasi reject ke UI klien.

## Location
`engine/download_manager.py:58`

## Current Behavior
Kunci antrean download ditarik secara polos tanpa sisipan fungsi batasan waktu (timeout) via `asyncio.wait_for`. Bila eksekusi internal (_yt-dlp hook_) macet/membeku, task pen-download lainnya akan mengantre permanen tanpa henti.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Gunakan mekanisme penguncian (contoh: asyncio.Lock) untuk mencegah race condition. Bungkus akses variabel mutasi dalam blok `async with lock:`.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
