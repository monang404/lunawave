# Task ID: S05-064

**Title:** Stream URL TTL di Batas Bawah Kedaluwarsa YouTube
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** TODO

## Source Audit
[CAC-02]

## Root Cause
Interval wajar ketahanan string referensi yt-dlp URL disetel ngawur 6 jam mutlak (21600), padahal youtube dapat memutuskan URL kurang dari range wajar ini sedikit, memicu link expired dipanggil sebagai link wajar (403 terlarang).

## Location
`config.py:28`

## Current Behavior
Batas kadaluwarsa tautan (TTL) hasil ekstraksi `yt-dlp` dipaku mutlak selama `21600` detik (6 jam). URL video internal YouTube dapat hangus prematur sedikit di bawah nilai ini, memicu putusnya streaming sebelum TTL dicabut dari memori.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Implementasikan mekanisme garbage collection atau batas ukuran (max limit) serta timeout/pruning untuk mencegah kebocoran memori (memory leak).

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
