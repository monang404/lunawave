# Task ID: S05-005

**Title:** Fake beat loop berjalan terus menerus
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** DONE

## Source Audit
[EXEC-015, FE-018]

## Root Cause
Loop efek kelap-kelip cahaya (glow) dieksekusi setTimeout() yang gagal termatikan secara sistem disaat viewport page tertutup, dan mengabaikan mode perlindungan (prefers-reduced-motion) dari penyandang disabilitas syaraf visual. Fake beat loop menggunakan requestAnimationFrame terus berjalan walau tidak ada perubahan visual yang dibutuhkan, membuang sumber daya CPU khususnya di perangkat mobile.

## Location
`web/static/js/audio.js:73-75`

## Current Behavior
`startFakeBeatLoop` dieksekusi menggunakan loop `requestAnimationFrame` dan `setTimeout` secara terus-menerus tanpa memberhentikan event ketika page ter-hide.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Tambahkan validasi `document.hidden` dan `window.matchMedia('(prefers-reduced-motion: reduce)')` pada loop animasi, serta pastikan `setTimeout` di-clear dengan benar saat animasi dihentikan.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
