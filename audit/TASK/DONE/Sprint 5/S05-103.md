# Task ID: S05-103

**Title:** Port Binding ke 0.0.0.0 Tanpa Firewall Layer
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** TODO

## Source Audit
[DEVOPS-005]

## Root Cause
Ekstraksi map binding port pada konfigurasi docker (0.0.0.0:8765) dengan ceroboh mengekspos rute langsung aplikasi mentah ke ranah internet publik bila perangkat punya public IP. Beresiko ditembus penyusup tanpa pelindung firewall reverse proxy tambahan (seperti nginx).

## Location
`docker-compose.yml:7-8`

## Current Behavior
Port binding `8765:8765` tanpa spesifikasi host localhost (`127.0.0.1:8765:8765`) di Docker mem-bypass firewall ufw secara default iptables dan terekspos mentah-mentah ke IP 0.0.0.0 publik.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
