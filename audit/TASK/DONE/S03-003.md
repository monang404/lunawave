## Root Cause
Query discover ke SQLite (get_recent, get_favorites, dsb) dipanggil dengan eksekusi await berurutan, menimbulkan latensi hingga +80-200ms per panggilan karena penumpukan di environment single-connection.

## Location
`server/handlers/ws/discover_handlers.py:19-23`

## Current Behavior
Kelima tabel / sumber agregasi _discover_ dieksekusi menunggu berantai (_serial_). Jika 1 baris memakan waktu 15ms, maka klien harus menunggu 75ms hanya untuk mengekstrak struktur query yang padahal bisa ditembakkan independen dengan `asyncio.gather`.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
