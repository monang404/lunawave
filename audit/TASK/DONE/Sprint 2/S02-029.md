# Task ID: S02-029

**Title:** Daemon _summary_worker dan _status_bar_worker tak punya kondisi henti
**Priority:** P2
**Sprint:** sprint-02-stability
**Status:** DONE

## Source Audit
[BUG-B27]

## Root Cause
Membiarkan worker memutar infinite loop dengan while True. Hal ini memaksa thread harus dibunuh oleh interpreter saat aplikasi mati. Akan lebih baik menggunakan event handler .wait() untuk exit condition.

## Location
`core/log_config.py:119-122`

## Current Behavior
Memang benar bahwa daemon thread `_summary_worker` dirancang mengeksekusi iterasi loop `while True` tanpa event `.wait()` maupun parameter exit flag. (Catatan: `_status_bar_worker` sudah memiliki `_status_bar_active`).

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Terapkan `asyncio.wait_for(..., timeout=...)` pada antrean untuk mencegah proses menggantung tanpa batas (deadlock).

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
