## Root Cause
Default value string kosong pada TrackEndedEvent.reason tidak ditangani dalam statement kondisional fungsi _on_track_ended(). Jika reason bukan eof/stop/error, fungsi tersebut akan langsung return tanpa melakukan apapun dan autoplay mati diam-diam.

## Location
`engine/playback/controller.py:173-192`

## Current Behavior
Parameter logis untuk string `reason` bernilai kosong (seperti "") yang terlewat dari kondisi "eof", "stop", maupun "error" akan diabaikan total, membuat lagu berikutnya gagal diputar (autoplay mati).

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Jangan menggunakan blok 'bare except' atau Exception generik. Tangkap spesifik Error yang diharapkan (misal ValueError/KeyError) dan log dengan formatter yang tepat menggunakan logger sistem, bukan sekadar diprint.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
