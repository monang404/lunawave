## Root Cause
Pada saat terjadi kegagalan proses ekstraksi warna, callback akan mengembalikan nilai primitif string untuk kode css. Tapi pemanggilnya hanya menyiapkan diri mengolah object {r,g,b}, sehingga berakibat inkonsistensi render halaman.

## Location
`web/static/js/utils.js:194-196`

## Current Behavior
Fungsi pemanggil ekstraksi warna `extractDominantColor` memberikan String CSS `"var(--bg-elevated)"` saat catch error, sedangkan ekspektasi balasan di mana-mana seharusnya berupa Object `{r,g,b}`.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Tangkap spesifik Error yang diharapkan (misal ValueError/KeyError) dan log dengan formatter yang tepat menggunakan logger sistem, bukan sekadar diprint.
