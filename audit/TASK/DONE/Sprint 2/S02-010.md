# Task ID: S02-010

**Title:** play_track retry backoff membaca _retry_count stale
**Priority:** P2
**Sprint:** sprint-02-stability
**Status:** DONE

## Source Audit
[BUG-B04, CC-03]

## Root Cause
Variabel self._retry_count dibaca di luar blok _play_lock yang mana nilainya bisa berubah akibat intervensi eksekusi fungsi lain di sela-sela pembebasan lock tersebut, mengakibatkan nilai sleep(backoff) yang tidak terprediksi. Formula hitung limit hitback retry dijalankan dari titik poin blok setelah proses di luar lock mutex terputus-sambung dengan coroutine lain, mengijinkan pembacaan iterasi (retry count) menyadur nilai kusam (stale) dan men-trigger skip lompat error.

## Location
`engine/playback/controller.py:146-150`

## Current Behavior
Pembacaan variabel statis `self._retry_count` terjadi di luar jangkauan blok mutex pelindung `async with self._play_lock`, rentan mengalami data race saat diakses paralel.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Gunakan mekanisme penguncian (contoh: asyncio.Lock) untuk mencegah race condition. Bungkus akses variabel mutasi dalam blok `async with lock:`.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
