# Task ID: S02-034

**Title:** Handlers websocket melempar Long Parameter List secara terpusat
**Priority:** P2
**Sprint:** sprint-02-stability
**Status:** TODO

## Source Audit
[CS-005, MAINT-A-03]

## Root Cause
Tiap bongkahan 26 fungsi Websocket terjangkit penyakit duplikasi primitive parameter. Meng-copy paste urutan argumen parameter 7 fungsi bawaan kemana-mana. Repot manakala jika satu butuh module tambahan event_bus, seluruh 26 file harus diotak-atik semua. Setiap WS handler diinisialisasi dengan tujuh parameter serupa yang tidak semuanya digunakan, memaksakan interface pattern secara artifisial.

## Location
`server/handlers/ws/discover_handlers.py:40`

## Current Behavior
Semua fungsi socket (contoh: Search, QueueSelect, Volume) memiliki pemaksaan tipe injeksi long-list dependency parameter yang selalu kembar-7 (data, ws, state, ytdlp, manager, db, command_bus) yang padahal tidak semua argumen dipakai. Modifikasi satu _signature_ parameter memaksa perubahan di 26 handler file WS.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
