## Root Cause
Panggilan library internal "import time" malah tertinggal nyelip berantakan di ujung bawah file (baris 300) gara-gara sisa artefak copy-paste. Keluar dari area top-level class. Pemanggilan modul time.monotonic() dilakukan di dalam method _handle_event namun import time diletakkan di baris paling terakhir dalam file tersebut. Ini memicu NameError jika dieksekusi sebelum modul berhasil diinisialisasi secara utuh. Penulisan modul import time dilempar pada baris paling bawah kode di luar class. Pema...

## Location
`engine/mpv_controller.py:298-301`

## Current Behavior
Import time benar-benar tergeletak begitu saja di baris terbawah (di luar _scope_ class dan top file), yang berisiko memicu NameError bila modul `time` dipanggil dari dalam eksekusi _method_ sebelum baris terakhir selesai terbaca.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Pindahkan deklarasi modul `import` ke bagian paling atas file sesuai PEP 8.

## Constraints

- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
