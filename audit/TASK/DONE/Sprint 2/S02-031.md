## Root Cause
File utilitas memanggil constant ITUNES_API_URL untuk keperluan pengambilan metadata cover lagu di iTunes, tapi variabel ini tak terdefinisi di mana pun dalam codebase. Ini memicu ReferenceError pada browser dan menyembunyikan semua artwork UI.

## Location
`web/static/js/utils.js:91-92`

## Current Behavior
`ITUNES_API_URL` tidak didefinisikan sama sekali di dalam kode scope `utils.js` maupun global `bundle.js`, sehingga dapat memicu `ReferenceError` pada _browser_ saat fetch iTunes.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Tangkap spesifik Error yang diharapkan (misal ValueError/KeyError) dan log dengan formatter yang tepat menggunakan logger sistem, bukan sekadar diprint.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
