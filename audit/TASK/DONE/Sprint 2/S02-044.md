## Root Cause
Parameter mode pemutaran radio diproteksi if statement ketat yang mensyaratkan status radio sedang aktif untuk fungsi pengacakan seed artist. Alhasil, klik acak dari antrean biasa diblok mentah dengan notifikasi log saja (harus 2 klik baru jalan).

## Location
`engine/playback/radio_commands.py:20-21`

## Current Behavior
Kode pada fungsi perombakan acak radio (`on_radio_randomize`) membungkus dirinya di bawah perlindungan `if self.state.playback_mode == PlaybackMode.RADIO:` secara telak. Sehingga kalau state masih Mode Antrean Biasa, instruksi ini tertahan total.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.
