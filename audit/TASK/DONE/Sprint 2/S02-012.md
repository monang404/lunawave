**Title:** _lock di PlaybackController dideklarasikan tapi tidak digunakan
**Priority:** P2
**Sprint:** sprint-02-stability
**Status:** TODO

## Source Audit
[BUG-B07]

## Root Cause
PlaybackController memiliki self._lock = asyncio.Lock() namun tidak pernah memanggil lock tersebut pada operasinya secara internal, sehingga subscriber event tetap memutasi state tanpa lock, menimbulkan false sense of security.

## Location
`engine/playback/controller.py:59`

## Current Behavior
Objek mutex `self._lock` dideklarasikan namun tidak pernah sekalipun dipanggil pada scope internal kelas `PlaybackController` tersebut.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Gunakan mekanisme penguncian (contoh: asyncio.Lock) untuk mencegah race condition. Bungkus akses variabel mutasi dalam blok `async with lock:`.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
