# Task ID: S02-025

**Title:** TrackInfo.from_dict mendiamkan ValueError karena video_id hash invalid
**Priority:** P2
**Sprint:** sprint-02-stability
**Status:** DONE

## Source Audit
[BUG-B23]

## Root Cause
YtDlpClient menghasilkan fallback hash yang panjangnya melebihi validasi ID (11 huruf), sehingga VideoId() di TrackInfo melempar exception ValueError. Akibatnya object dikonversi jadi None dan request gagal diam-diam.

## Location
`core/state.py:62-64`

## Current Behavior
Objek TrackInfo diam-diam menelan eksepsi `ValueError` jika hash ID tidak valid dan langsung membalikkan balasan kosong `None` tanpa meninggalkan jejak log error.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Jangan menggunakan blok 'bare except' atau Exception generik. Tangkap spesifik Error yang diharapkan (misal ValueError/KeyError) dan log dengan formatter yang tepat menggunakan logger sistem, bukan sekadar diprint.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
