# Task ID: S05-016

**Title:** SQLite hanya single instance
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** DONE

## Source Audit
[EXEC-032, DB-001]

## Root Cause
Aplikasi menggunakan single SQLite instance dengan satu koneksi, yang menghalangi kemampuannya untuk divaluasi secara horizontal (scale out). Seluruh aktivitas database (read dan write) dibebankan pada satu pool aiosqlite, menyebabkan seluruh eksekusi coroutine harus antre sekuensial. Saat workload tinggi, bisa mengunci seluruh jalannya aplikasi secara paralel.

## Location
`cache/db.py:33`

## Current Behavior
Aplikasi murni menggunakan 1 (satu) koneksi tunggal SQLite `_conn` yang dipakai bergantian, sama sekali tidak menggunakan connection pooler.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
