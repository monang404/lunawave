## Root Cause
Tembakan minimal os python beda-beda belangsak pada 3 setting file. Pyproject bilang >=3.10, CI di 3.11, Docker di 3.12. Membuat kelolosan error ga singkron (test lolos di versi 3.11 tapi jebol deprecated library pas di-docker pake versi 3.12).

## Location
`pyproject.toml:10 vs Dockerfile:1`

## Current Behavior
Definisi rentang minimal lingkungan Python tercerai-berai cacat selaras; di mana berkas _Toml_ spesifikasi aplikasi menuntut ">=3.10", pengujian lintasan CI Github di "3.11", sedangkan pengepakan mutlak _Docker_ dipatok paten di "3.12".

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Tulis unit test/integration test baru menggunakan mock yang mensimulasikan lingkungan sebenarnya (misalnya HTTP request asli) yang diverifikasi dengan assertion.

- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
