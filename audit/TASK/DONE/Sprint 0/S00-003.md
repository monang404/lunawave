**Title:** Missing Index untuk Favorites Query
**Priority:** P0

## Source Audit
[PERF-P12, DB-009]

## Root Cause
Parameter penanda favorite pada daftar lagu tidak ditopang tabel indeks sama sekali. Daftar lagu terfavorit hanya dapat disajikan dengan full table scan, yang melambat linear seiring data. Tabel lagu SQL tidak dioptimasi menggunakan partial index komposit pada pola filter 'is_favorite = 1'. Server terpaksa membaca seluruh database (full scan), memunculkan hambatan pada jumlah entri masif.

## Location
`cache/schema.sql:19-22`

## Current Behavior
Sama sekali tak terdapat formasi blok index semisal `CREATE INDEX idx_is_favorite ON tracks(is_favorite)` guna mempercepat query perburuan daftar lagu-lagu favorit pada dataset ratusan item lagu.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.
