**Priority:** P0

[DEVOPS-001]

## Root Cause
Titik eksekusi container (CMD) pada Dockerfile dengan ceroboh di-set untuk memanggil "run.py", yang mana sama sekali tak ada dalam direktori aplikasi (hanya ada main.py). Membuat deployment otomatis langsung crash seketika (fatal).

## Location
`Dockerfile:28`

## Current Behavior
Instruksi default image container menunjuk ke skrip awalan `run.py` yang jelas-jelas tidak eksis / fiktif di dalam root folder project (seharusnya `start.py`), menjamin crash fatal saat run.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
