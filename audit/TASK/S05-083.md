## Root Cause
Security linter Bandit dimatikan pemindai /tmp (B108). Membiasakan taruh folder temp ke hardcode absolut (/tmp) di os linux rawan serangan racun symlink jika sistem berjenis multi-user, karena hacker user sebelah dapat menumpuk folder palsu pakai nama yg sama.

## Location
`pyproject.toml:60`

## Current Behavior
Parameter pengaturan `skips` sengaja memandulkan pemindai kerentanan Bandit `B108` (detektor peletakan path darurat absolut di sistem /tmp), menelanjangi server peramban dari penangkapan dini racun simpul taut (_symlink poison_) lokal.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.
