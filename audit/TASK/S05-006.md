## Root Cause
Aiohttp berjalan single-threaded tanpa worker pool, sehingga request lambat dari yt-dlp dapat menghalangi progress broadcast ke semua client.

## Location
`server/app.py:48-51`

## Current Behavior
Server aiohttp dieksekusi tunggal via `web.AppRunner(app)` pada root asyncio loop tanpa worker pool sama sekali (misal gunicorn).

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
