# Task ID: S05-070

**Title:** docker-compose.yml Tidak Meneruskan Secrets dari Environment
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** TODO

## Source Audit
[DEVOPS-014]

## Root Cause
Struktur pembungkus compose environment abai tidak mendistribusikan turunan secret-token maupun pasword rahasia server (seperti LUNAWAVE_ADMIN_PASS). Membuat setting manual env luar tertelan dan wadah terpaksa meng-generate kunci random terus.

## Location
`docker-compose.yml:13-14`

## Current Behavior
Blok `environment` pada deklarasi `docker-compose.yml` sama sekali tak memetakan operan rahasia kata sandi `LUNAWAVE_ADMIN_PASS` maupun port `LUNAWAVE_PORT`, menyia-nyiakan fitur injeksi secret aman ke kontainer.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Identifikasi alur spesifik dari bug ini dan pastikan ada perbaikan yang memitigasi dampak dari masalah yang disebutkan di current behavior. Pastikan solusi aman dari sisi arsitektur.

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
