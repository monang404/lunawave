# Task ID: S05-044

**Title:** Tidak Ada HTTP Request Timeout untuk Proxy Stream
**Priority:** P3
**Sprint:** sprint-05-maintainability
**Status:** TODO

## Source Audit
[API-07]

## Root Cause
Sambungan eksternal get-request ke server stream Youtube tidak mencantumkan parameter timeout sama sekali. Apabila target mengalami hang atau menunda respons, request akan nyangkut menyedot ketersediaan proses worker backend selamanya.

## Location
`server/handlers/http.py:151-189`

## Current Behavior
Pengambilan bitrate aliran lagu menggunakan peramban aiohttp (`http_session.get()`) meloloskan argumen `timeout`, membuat program menunggu dalam kekekalan / limit default abadi bila server _Google Video_ tak sengaja mengalami bad-gateway.

## Expected Fix
Lakukan refactor/perbaikan pada lokasi kode terkait agar sesuai dengan arsitektur yang aman dan benar. Terapkan `asyncio.wait_for(..., timeout=...)` pada antrean untuk mencegah proses menggantung tanpa batas (deadlock).

## Constraints
- Tidak boleh merusak kapabilitas streaming inti dari player MPV.
- Modifikasi arsitektur tidak boleh mengorbankan performa saat melayani banyak websocket connection.
- Ikuti standard code quality dan format di `Task_execution_rules.md`.
